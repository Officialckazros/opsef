This file documents everything added/changed in the big upgrade:

------------------------------------------------------------------------------
 1. SMARTER MODEL + DUAL ROUTING
------------------------------------------------------------------------------
BEFORE
  - Single model via SEFBOT_MODEL (often llama-3.1-8b-instant in production).
  - Every task (chat, custom cmds, reflection) used the same model.

AFTER
  - Three tiers in config.py / ai.py:
      SEFBOT_MODEL_SMART  default llama-3.3-70b-versatile  (main brain/chat)
      SEFBOT_MODEL_FAST   default llama-3.1-8b-instant     (cheap tasks)
      SEFBOT_MODEL_VISION default meta-llama/llama-4-scout-17b-16e-instruct
  - SEFBOT_MODEL still works as an alias for the smart model.
  - ai.chat / ai.structured / ai.json_call accept tier="smart"|"fast"|"vision".
  - Routing map:
      * Chat / structured brain / vibecheck / recap / roastbattle / whoami
        / reflection / !request design  → SMART
      * Community command runs / lurk quips / trivia question gen → FAST
      * Image attachments → VISION (describe_images)
  - !models shows the three active model ids.
  - on_ready logs all three models.

FILES
  config.py, ai.py, bot.py, customcmds.py, .env.example


------------------------------------------------------------------------------
 2. PER-USER RELATIONSHIP / BOND
------------------------------------------------------------------------------
NEW
  - SQLite table `relationships` (user_id, guild_id, score -1..+1,
    nickname, grudge, bond_label).
  - Bond labels: stranger → cool with → friend → ride-or-die
                 / annoying → rival → nemesis
  - Injected into every system prompt for that user.
  - Model JSON field `relationship: {delta, nickname, grudge}` applied
    after each reply.
  - 👍/👎 also nudges the reactor's bond.
  - Commands:
      !bond [@user]           show score / nick / grudge
      !relationship           alias
      !rivalries              worst + best bonds on the server
  - !stats shows YOUR bond with the bot.

FILES
  db.py, brain.py, bot.py


------------------------------------------------------------------------------
 3. SHORT-TERM CONVERSATION MEMORY
------------------------------------------------------------------------------
NEW
  - Table `conversations` stores last N user↔bot turns per person per guild.
  - Config: SEFBOT_CONVO_TURNS (default 8 pairs worth of rows).
  - Injected into the system prompt so multi-turn banter stays consistent.
  - !resetconvo clears short-term history (long-term memories stay).

FILES
  db.py, brain.py, bot.py, config.py


------------------------------------------------------------------------------
 4. GUILD PERSONA LOCK
------------------------------------------------------------------------------
NEW
  - Table `guild_settings` JSON blob per guild.
  - !persona / !persona set <text> / !persona clear / !persona show
  - Manage-server required to set/clear.
  - build_system uses guild persona when set, else global PERSONA.

FILES
  db.py, brain.py, bot.py


------------------------------------------------------------------------------
 5. SMARTER MEMORY
------------------------------------------------------------------------------
BEFORE
  - Blind insert of every model-emitted fact (duplicates piled up).

AFTER
  - add_memory() merges near-duplicates (token Jaccard ≥ 0.45):
      boosts importance, keeps richer text, updates `updated` column.
  - Soft cap SEFBOT_MEMORY_SOFT_CAP (default 40): drops weak facts or
    decays importance of excess rows.
  - update_memory() for edits.
  - compact_memories() keeps top-N by importance.
  - Commands:
      !memory edit <id> <text>
      !memory compact [@user]
      !memory erase [@user]   (already existed; kept)
  - !memories lists importance scores.
  - Server fact retrieval scores by keyword overlap AND importance.

FILES
  db.py, brain.py, bot.py


------------------------------------------------------------------------------
 6. PROACTIVE LURK (OPT-IN)
------------------------------------------------------------------------------
NEW
  - Background task _lurk_loop every 60s.
  - Per guild: !lurk on (this channel) / !lurk off  (manage server).
  - Fires when channel idle ≥ SEFBOT_LURK_IDLE_SECONDS and last lurk
    ≥ SEFBOT_LURK_MIN_SECONDS ago.
  - Uses FAST model for a short unprompted quip embed titled "lurk".
  - Tracks last activity from on_message.

FILES
  bot.py, config.py, db.py (guild_settings.lurk, lurk_channel)

 BEHAVIOR CHANGE NOTES
------------------------------------------------------------------------------
  - Main chat now prefers the 70B smart model (unless env overrides).
  - Bot is warmer/colder per person based on bond score.
  - Multi-turn conversations with the same person feel continuous.
  - Guilds can customize persona and swear level without redeploy.
  - Memory spam should decrease due to merge + soft cap.
  - Optional lurk can make the bot feel "alive" in quiet channels.
  - No background-check / auto-dox feature (removed earlier; stays gone).
  - Existing slash.py layer kept: execute_all(requester, guild, client) signature
    preserved; slash /chat also gets relationships, quotes, convo, smart model.

 DESKTOP PET (SefPet) — NEW
------------------------------------------------------------------------------
NEW
  - `desktoppet/` — a standalone desktop pet app (PySide6/Qt).
  - Lives on the desktop: frameless, transparent, always-on-top window.
  - Wanders along the bottom of the screen, flips to face direction, drag
    anywhere with the mouse.
  - Speech bubbles with typewriter effect + real text-to-speech
    (macOS `say`, Windows SAPI, Linux espeak — no extra deps).
  - Ask it questions: AI brain via any OpenAI-compatible endpoint
    (SEFPET_AI_KEY/BASE_URL/MODEL, falls back to GROQ_API_KEY etc.), plus a
    built-in offline brain (jokes, facts, math, time, games, chat).
  - Mood system: hunger / happiness / energy decay over time, idle chatter.
  - Interactions: click (boop), double-click (headpat), right-click menu
    (feed, pet, play, ask, jokes, facts, time, dice, sing, sleep, settings).
  - Settings persisted to ~/.sefpet/config.json; system tray; custom sprite.
  - Packaged with PyInstaller for Windows (exe) and macOS (app).
  - `.github/workflows/release.yml` builds + attaches release assets on tag push.

FILES
  desktoppet/pet.py, desktoppet/README.md, desktoppet/requirements.txt,
  desktoppet/build_mac.sh, desktoppet/build_windows.ps1,
  .github/workflows/release.yml
